# 导出合同排版优化 — 实施计划书

> 状态：待评审 | 日期：2026-08-16 | 范围：`backend/core/contract_merger.py` + `clause_parser.py`（可选）

---

## 1. 问题定位（三个瑕疵的根因）

### 瑕疵 1：标题重复 + 标签混入正文

**现象**（实测「模拟合同2_房屋租赁合同_修订后.docx」）：

```
模拟合同2_房屋租赁合同      ← 文件名标题（Title 样式）
合同标题                    ← 机器标签，不该出现
房屋租赁合同                ← 真实标题，本该当主标题
当事人信息                  ← 机器标签，不该出现
出租人（甲方）：xxx          ← 真实内容
...
签署落款                    ← 机器标签，不该出现
甲方（盖章）：xxx
```

**根因**：`clause_parser.parse_clauses` 用 LLM 结构化抽取，prompt 虽要求「标题/声明/落款等非实质性内容，type 设为空字符串」，但 LLM 实际把「合同标题」「当事人信息」「前言声明」「签署落款」这些**辅助标签**填进了 `title` 字段。导出时 `merge_clauses` 把所有 `title` 一律当加粗标题输出，导致机器标签混入正文、真实标题被埋没。

### 瑕疵 2：排版偏素

`build_contract_docx` 只有「heading(0) + 加粗段落 + 普通段落」两层，无字号层级、行距、首行缩进。

### 瑕疵 3：无页眉页脚

`build_contract_docx` 未设置页眉/页码，不像正式文件。

---

## 2. 修复方案（集中在 `contract_merger.py`）

### 2.1 瑕疵 1：标签类 clause 过滤（merger 层防御 + parser 层治本）

**标签识别规则**（在 `build_contract_docx` / `build_contract_text` 里加）：

| 判断 | 处理 |
|---|---|
| `title` 含「第X条/章/节」 | ✅ 真实条款 → 加粗标题 + 正文 |
| `title` ∈ 标签白名单（合同标题/合同编号/当事人信息/前言/前言声明/签署栏/签署落款/标题 等） | ⚠️ 过滤标签，只输出 `content` |
| `title` 为空 | 只输出 `content` |

**标题类 clause 特殊处理**：`title=="合同标题"`（或首个 clause 且 content 是短标题）时，取其 `content` 作为**文档主标题**（"房屋租赁合同"），不再输出"合同标题"标签，也不再用文件名当标题。

**效果**：

```
房屋租赁合同            ← 唯一主标题（Heading 0，居中）
出租人（甲方）：xxx       ← 直接列内容，无"当事人信息"标签
第一条 租赁房屋及用途     ← 真实条款，加粗标题
1.1 xxx                  ← 正文
...
甲方（盖章）：xxx         ← 直接列落款，无"签署落款"标签
```

**可选治本**（`clause_parser.py`）：prompt 里把「标题/声明/落款 type 与 title 均设为空」的约束写得更硬，降低 LLM 再填标签的概率。注意：**只对新审查生效**，历史数据靠 merger 层防御性过滤兜底。

### 2.2 瑕疵 2：排版规范（对齐中文合同惯例）

| 元素 | 规范 |
|---|---|
| 合同主标题 | 黑体 22pt（二号），居中 |
| 条款标题（第X条） | 黑体 12pt，加粗 |
| 正文 | 仿宋 12pt（小四），1.5 倍行距，首行缩进 2 字符 |
| 分条款（1.1 / 2.1） | 仿宋 12pt，首行缩进 2 字符 |

技术要点：python-docx 设置中文字体需同时设 `run.font.name` 与 `rPr.rFonts.set(qn('w:eastAsia'), '仿宋')`，否则中文可能回退默认字体。

### 2.3 瑕疵 3：页眉页脚

| 位置 | 内容 |
|---|---|
| 页眉 | 合同名（宋体 9pt，居中） |
| 页脚 | 页码（宋体 9pt，居中，`PAGE` 域） |

## 4. 测试与验收

- **单测**（`tests/test_contract_merger.py` 增补）：
  - `title=="合同标题"` → 提取 content 为主标题，不输出"合同标题"标签
  - `title=="当事人信息"/"签署落款"` → 只输出 content，不输出标签
  - `title=="第一条 租赁期限"` → 加粗标题 + 正文，不变
  - docx 结构断言：标题居中、正文含首行缩进、有页眉页脚
- **端到端**：重新导出「模拟合同2」→ 核验：主标题唯一、"当事人信息"标签消失、条款标题层级正确、页眉有合同名、页脚有页码
- **回归**：`test_multi_dim` + `test_graph_smoke` 不回归

---

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| LLM 填的标签不完全在白名单内（出现新标签） | 白名单 + 兜底规则：`title` 不含「第X条/章/节」且 ≤6 字 视为标签候选，一并过滤 |
| 中文字体（黑体/仿宋）在用户机器缺失 | 字体缺失时 Word 自动回退宋体，不报错；可接受 |
| 过滤标签导致"前言/声明"内容被误删 | 只过滤 `title`（标签），`content` 永远保留 |
